# 本机真实学习模式

该模式在已有受控网页入口上开放知识库创建/编辑、文档上传和确认删除，模型出口继续共享原累计预算账本。默认不开写权限，不用于公网部署。

## 启动

原开发环境保留真实.env、隔离业务库及预算账本。先在旧后端窗口Ctrl+C正常结束会话，再从backend目录显式启动：

```powershell
.\.venv\Scripts\python.exe tests/start_web_demo.py --enable-authorized-web-demo --enable-local-writes --session-name my-learning-01
```

前端仍为127.0.0.1:5189，API为127.0.0.1:8010。每次重新启动选择新的会话名，沿用已有累计风险预算，不初始化、删除或恢复历史账本；不是每次点击创建新轮次。浏览器刷新后即使用新接口。

## 权限与数据

- 只接受127.0.0.1客户端、127.0.0.1 Host和配置中的Origin，不信任代理转发头。
- `--enable-local-writes`显式开放知识库POST/PUT/DELETE、文档上传/DELETE。DELETE还需页面确认后发送X-Confirm-Delete:true。
- 历史Bailian-RAG-Live-Test知识库在本机模式下只读，禁止编辑、上传或删除它及其资料。
- 同一服务串行处理写入/模型任务；每分钟12次操作，拒绝排队积压。只读列表不触发模型。
- 不开放持久化历史会话或记忆接口；没有原地重新索引API，失败文件保留failed记录，可确认删除后重新上传。模型异常须先处理安全会话状态，不能自动恢复HALTED。

## 上传与费用

- 支持PDF、DOCX、TXT、Markdown。2 MiB/文件；解析文本120000字符，最多128片，每片目标640字符、重叠80字符、UTF-8不超过1984字节；每批8条Embedding、最多16批，详见[DOCX离线修复](docx-chunk-fix.md)。
- 解析完成、第一次Embedding之前，按每片UTF-8长度×4+256估算输入，核对整份资料及每批最多一次重试的费用和剩余会话请求数。不够时不启动任何Embedding。
- 真实模式先显示本地分析结果，用户再确认生成索引；已有failed记录可直接分析原文件并确认重试，无需删除原文，不自动收费重跑。
- 整份资料检查是准入预估，每次真实HTTP仍单独原子预扣，其他进程也不能绕过累计¥50。不存在单轮金额限制。
- 批量失败时删除该新文件的不完整索引和Chunk，保留失败文档；已消耗费用不退回。启动恢复逻辑沿用既有状态机。
- 文件无效、重复名或不存在等未调用模型的用户输入错误不熔断整个会话；模型错误、未知usage、超预算等保留原异常熔断。
- 前端显示本机模式、上传费用及限额，区分权限拒绝、模型费用/会话保护和普通处理错误。全部模型重试仍通过Guard，最多一次瞬时重试。
